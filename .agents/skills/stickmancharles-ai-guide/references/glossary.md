# Small distinctions for the current question

Use for a quick lookup or a single unfamiliar term. Do not read this table aloud as a lesson or treat it as the full book glossary.

| Term | Useful distinction |
|---|---|
| Project root | The directory that anchors this project’s files and commands; it may differ from the current terminal directory |
| Source / config | Implementation / settings consumed by tools or runtime; both can change behavior |
| Dependency / lockfile | A package the project uses / the resolved dependency versions for reproducible installation |
| Runtime / build | Where code executes / transformation into runnable or deployable output |
| Entry point | Where execution or a request first enters this part of the program |
| Repository / working tree | Git’s tracked history and metadata / files currently checked out for work |
| Stage / commit / push | Select changes / record a local snapshot / send commits to a remote |
| Branch / remote | A named line of history / another repository used for exchange |
| Pull / PR | Fetch and integrate changes / propose and discuss changes before merging |
| Issue | A tracked question, bug, or task; it is not a code change itself |
| API / endpoint | A callable interface / a specific operation or address in that interface |
| Authentication / authorization | Establish identity / decide what that identity can do |
| Schema / migration | Data structure / recorded change to that structure |
| Typecheck / test | Check declared code shapes / check selected observable behavior |
| Log / monitoring / alert | Recorded events / ongoing measurement / notification that may require action |
| Local / preview / production | Developer environment / review environment / environment serving real users |

Use an analogy only if it helps this learner, then connect it to the actual artifact. For example, a repository is more than “a folder,” and passing type checks is less than proof that runtime data is valid. A precise distinction often teaches more than a memorized definition.

For terms not needed to complete the task, offer the canonical glossary for later reading rather than expanding the context now.
