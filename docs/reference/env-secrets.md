# 环境变量与密钥

> 代码要流传，秘密不能流传。

## 认脸
- 判断法：陌生人拿到会怎样？能花钱/动数据/冒充你 = 秘密 = 进环境变量
- `.env` 永不进 Git（`.gitignore` 把守）；`.env.example` 只列名字，可进
- 泄露了：**立刻作废换新**，Git 历史里它还在，删代码没用

## 常见坑
- 把 key 写进代码"先跑起来再说"：扫库机器人几分钟就能找到它
- SSH 私钥的最高纪律：永不离开你的电脑，永不发给任何人——**包括 AI**
