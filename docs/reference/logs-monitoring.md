# 日志与监控

> 让你永远比用户先知道。

## 认脸
- 三件套：日志（出事后翻的日记）· 监控（值班的眼睛）· 告警（该行动才响的铃）
- 排障咒语：**症状定层，层定日志**
- 打日志家规：关键动作留痕；错误带上下文；秘密永不进日志

## 常见坑
- 会响但不用行动的告警 = 给自己安装"狼来了"——宁少勿滥
- 用户说"昨晚打不开"你毫不知情：缺一个 uptime 探针
