# Markdown · MDX

> 文档语言：你和 AI 的母语交汇点。

## 认脸
- 十分钟学完：`#` 标题、`**粗体**`、`-` 列表、链接、代码块、表格
- MDX = Markdown + 可嵌组件；**大写开头 = 组件，小写 = HTML**
- front matter：文件顶部两条 `---` 夹着的名片（YAML）

## 常见坑
- 文档不进 Git：进了 Git 才能 diff、才能 PR、才能审查
- YAML 缩进错一格整个文件瘫痪——对齐是命
