# 验证与调试

> AI 说"完成了"，不等于完成了。

## 认脸
- 验证金字塔：能跑吗 → 功能对吗 → 边界情况 → 真实用户会遇到什么
- 报错是礼物：原样完整贴给 AI，比转述"它好像坏了"有用十倍
- 高级三招：最小复现 · 换个会话重来 · "删掉这行会发生什么？"

## 常见坑
- 只走正常路径：翻车九成翻在边界（空输入、连点两次、断网）
- 在一条错误假设上和 AI 纠缠到底：新会话、重新描述，常常瞬间解开
