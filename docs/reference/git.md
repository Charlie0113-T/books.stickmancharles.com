# Git

> 代码的时间机器：存档、平行宇宙、随时回滚。

## 认脸
- 三区模型：工作区（稿纸）→ 暂存区（打包台，add）→ 仓库（存档柜，commit）
- 四步循环：`status` → `add` → `commit -m` → `push`；迷路先 `status`
- branch = 平行宇宙，merge = 合并宇宙

## 常见坑
- **没推的可以整理，推了的只能追加**——`reset --hard` + force push 改写公共历史，红线
- 一次 commit 塞十件事：历史成浆糊，回滚无从下手
