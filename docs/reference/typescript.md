# TypeScript

> 带"形状检查"的 JS：出错前就报警。

## 认脸
- 口诀：**遮住冒号读逻辑，再回头看形状**
- 类型 = 海关申报单；红波浪线 = 安检机在喊"形状不对"
- 报错句式：`Type A is not assignable to type B` —— A 塞不进 B

## 常见坑
- 改了逻辑不改类型（或反过来）：两半必须保持一致
- 把类型当负担：类型是给 AI 的说明书，越全 AI 越稳
