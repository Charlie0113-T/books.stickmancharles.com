# Vercel

> 前端全球分发 + 函数托管 + 连 GitHub 自动上新。

## 认脸
- 流水线：push → 拉代码 → build → 全球上线，全自动
- 三块田：localhost → **Preview（每次改动一个独立预览网址）** → Production
- 出事有回滚：一键退回上一个正常版本

## 常见坑
- 部署失败 90% 是三件事：环境变量没配、依赖版本、build 命令错——先看构建日志
- 本地好好的线上炸：本地被宽容、线上被严查
