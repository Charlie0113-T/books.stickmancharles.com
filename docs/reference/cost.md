# 成本

> 账单是用钱写成的监控日志。

## 认脸
- 三种计费形状：固定月租（封顶）· 用量计费（随用户涨）· 免费额度 + 超量
- 每月一次账单会：重点不是数字大小，是**和上月比有没有异动**
- 每家都设支出提醒；搞清超线后是"停"还是"扣"

## 常见坑
- 云上最常见的浪费：忘了它还在扣钱——定期下线僵尸项目
- 账单突跳 = 系统行为异动的影子：先看哪条用量线动了，再对时间查日志
