# Claude Code

> 两个形态：VS Code 里的贴身搭档，和云端接活的分身。

## 认脸
- 插件六步循环：说清 → 要计划 → 审差异 → 接受/打回 → 跑验证 → commit
- 网页版三动作：派活（任务书）→ 收货（看 PR）→ 裁决（合并或打回）
- 界面会变，工作循环不变

## 常见坑
- 一个会话干三件事：上下文混了，三件都走样——新任务开新会话
- 跳过"先要计划"直接放行：一半的返工来自这里
