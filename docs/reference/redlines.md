# 红线与不可逆

> 可逆的事放手让 AI 跑；不可逆的事，人是最后一道闸。

## 认脸
- 同一条定律出现三次：**进了公共世界的东西，只能追加，不能背叛**——链上合约、Git 公共历史、已发布的 API
- 红线动作：批量删除、force push、动生产库、群发、花真钱、改已部署合约
- 没有 WHERE 的 UPDATE/DELETE：立刻停下叫人

## 常见坑
- AI 解释得越合理越要警惕：它不知道你的红线在哪，除非你写下来
- 红线写进 CLAUDE.md 才算数——口头约定会被上下文挤出去
