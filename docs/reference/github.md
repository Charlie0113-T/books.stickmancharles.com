# GitHub

> Git 仓库的云端家园 + 协作大厅。

## 认脸
- 建空仓 + 三行咒语：`remote add origin` / `branch -M main` / `push -u origin main`
- PR = 正式的"请过目"；Files changed 里逐文件审红绿
- 动手之前先 `pull`

## 常见坑
- 云上建仓勾了自动 README，首推打架：让云上是完全的空仓
- 公开仓库里出现过的秘密 = 已泄露，作废换新，不是删代码
