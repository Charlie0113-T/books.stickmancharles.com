# 怎么提需求

> 把你脑子里的画面，传进 AI 脑子里。

## 认脸
- 万能骨架：**背景 + 目标 + 约束 + 例子**（一个好例子顶三段描述）
- 大活拆小：一次一个可验证的小步
- 先要计划再放行："先说打算怎么做，别写代码"——免掉一半返工

## 常见坑
- "改一下登录逻辑" vs "改 login.ts 里 handleSubmit"：指名道姓永远赢
- 异步派活（网页版）没有追问机会：规格写多清楚，成果就有多接近
