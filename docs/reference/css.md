# CSS

> 样式语言：长什么样，摆在哪。

## 认脸
- 一个句式重复到底：选择器 + `{ 属性: 值; }`
- 盒模型四层：内容 → padding → border → margin；"间距不对"九成在这
- Tailwind = 预制 class 字典，一个词一条规则，逐词可查

## 常见坑
- 改了不生效：被更具体的规则压住了（F12 里被划横线的就是）
- 满屏 Tailwind 看着吵——读法不变，不认识的词问 AI 一问一个准
