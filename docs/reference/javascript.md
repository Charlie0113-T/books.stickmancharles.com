# JavaScript

> 动作语言：数据、动作、触发时机。

## 认脸
- 四块积木：变量（const/let）、函数（含箭头 `=>`）、对象与数组、事件
- 读法先找三样：数据在哪、动作在哪、什么时候触发
- 同一门语言两个住处：浏览器（摸得到页面）和 Node.js（服务器）

## 常见坑
- `await` 忘了等：见到网络请求就该想到"去取数据，等它回来"
- 逐字抠语法：先通剧情，再抠不懂的行
