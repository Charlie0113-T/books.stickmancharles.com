# HTML

> 骨架语言：页面上有什么，谁包着谁。

## 认脸
- 三条规则读懂一切：标签成对、嵌套成树（DOM）、属性是设置项
- `class` 是给 CSS 认的名牌；`head` 给机器看，`body` 给人看
- F12 的 Elements 面板 = 那棵树的活体

## 常见坑
- 它不管好看（CSS 的事）也不管交互（JS 的事）——别在骨架里找皮肤
- 项目里很少有裸 .html：React 把它拆进了 .tsx
