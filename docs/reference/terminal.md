# 终端

> 和电脑说话的第二种方式——也是 AI 的手脚。

## 认脸
- 三个键先练成本能：**Tab 补全**、↑ 历史、Ctrl+C 中断
- 组合技：`grep -r` 全局搜、`tail -f` 追日志、`|` 流水线接力
- 你可以不常用它，但必须看得懂 AI 在里面敲什么

## 常见坑
- `rm` 没有回收站；见到 `rm -rf` 出现在 AI 的命令里，多看一眼再放行
- 路径打错不自知：养成 Tab 补全的习惯，拼写错误自然消失
