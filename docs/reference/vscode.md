# VS Code

> 每天坐进去的驾驶舱：编辑器、Git 图形界面、集成终端三合一。

## 认脸
- 活动栏五件套：文件树 / 全局搜索 / **源代码管理（Git 的图形脸）** / 调试 / 扩展
- `Cmd/Ctrl+P` 跳文件，`Cmd/Ctrl+Shift+P` 命令面板，`` Ctrl+` `` 集成终端
- 左下角状态栏 = 当前 Git 分支

## 常见坑
- 图形按钮和命令行是同一件事的两张脸——只认识一张，就看不懂 AI 在干什么
- 改完不 commit 就继续下一件事：存档点越稀，回滚越疼
