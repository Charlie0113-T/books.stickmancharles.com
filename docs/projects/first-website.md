# 从零上线第一个网站

半小时，十步，从一个空文件夹走到全世界都能访问的网址。这套流程出自[第二册第 12 章](/guide/02/ch12)，是我们每个新项目的骨架——第一次走，建议和爸爸/搭档一人操作一人对照书。

## 十步

1. 新建文件夹 `hello-web`，用 VS Code 打开。
2. 让 Claude 生成一个最小的个人主页——就一个 `index.html`，越简单越好（它日后还是[第三册第 2 章](/guide/03/ch02)的解剖标本）。
3. 源代码管理面板点"初始化仓库"（背后是 `git init`——给文件夹装上时间机器）。
4. add、commit，第一条存档说明："最小主页"。
5. GitHub 网页建一个**空**仓库（不勾任何初始化选项，否则首推打架）。
6. 三行咒语：`git remote add origin …` / `git branch -M main` / `git push -u origin main`（逐行人话翻译见[第二册第 6 章](/guide/02/ch06)）。
7. 打开 Vercel，Add New Project → Import 这个仓库 → 一路默认 → Deploy。
8. 拿到 `xxx.vercel.app` 网址，发给家人，让他们在手机上打开。**这是你从零上线的第一个网站。**
9. 回 VS Code 改一个词，add、commit、push——看 Vercel 自动重新构建、部署。[第一册第 11 章](/guide/01/ch11)画的流水线，此刻在你眼前真实转动。
10. 彩蛋（可选）：在 Cloudflare 给自己的域名加一条 CNAME 指向这个项目，让它拥有真正属于你的网址（[第四册第 1 章](/guide/04/ch01)）。

::: info 关键领悟
从空文件夹到全世界可访问：十步、半小时。这件事十年前需要一个团队。门槛已经消失了，剩下的只是把这十步走熟。
:::
