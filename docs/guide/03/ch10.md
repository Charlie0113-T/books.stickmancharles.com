# 第 10 章 实战：挑一个真实文件，和 AI 一起逐行读通

毕业课不讲新语言，讲一套<strong>陪读流程</strong>。六步，走完一次算毕业；以后每月一次，读的能力就会一直长。

1. <strong>选材</strong>。挑一个你项目里"每天路过但从没进去过"的文件。首选五十到一百五十行、角色清晰的：一个 React 组件、一个 API 函数，或者——最合适的毕业标本——我们的 `docs-prototype.html`：一个文件集齐了本册第 2、3、4 章（骨架、皮肤、动作三位一体）。
2. <strong>冷读五分钟</strong>。不查不问，写下三句话：它是什么语言、什么角色？分几大块？我最看不懂的是哪几行？先猜后问，猜过的才记得牢——第一册第 14 章"先猜再对答案"，原理相同。
3. <strong>让 AI 开导览</strong>。"把这个文件分成几个功能块，每块一句话概括，先别逐行。"先看地图，再进街巷——你已经习惯这个顺序了。
4. <strong>逐块细读</strong>。对最不懂的那块下钻："逐行解释，每一行为什么需要存在。"追问时用这把最锋利的刀：<strong>"删掉这一行，会发生什么？"</strong>——它逼出的答案，比"这行是什么意思"深十倍。
5. <strong>动一下</strong>。做一个五分钟级的小改：换句文案、调个颜色、改个数字。跑起来验证（第一册第 14 章金字塔），commit（第二册第 5 章）。<strong>读懂的标志不是能解释，是敢改。</strong>
6. <strong>收获入库</strong>。新词补进附录 A（上一章你已经会以作者身份改它了）；如果这个文件值得，给它在 CLAUDE.md 里记一行"它是干嘛的"——你的读书笔记，同时也是给 AI 的地图（第二册第 11 章）。

到这里，三册合龙：第一册教你认地图上的地名，第二册教你握方向盘，这一册教你读路上每一块路牌。你已经可以在这个世界里自己开车了。下一册，我们下车——打开引擎盖，看看四大件里面到底是怎么转的。

::: info 关键领悟
"读懂"的终点不是解释给自己听，而是<strong>敢做一个小改动，并亲手验证它</strong>。从解释到敢改之间隔着的那点信心，就是这一册想交给你的全部东西。
:::

::: tip 试一试
本周内完整走一次六步。把你选的文件名和三句冷读笔记发给爸爸，让他也走一次，互相当读者——两个人读同一个文件，看见的盲区不一样。
:::
