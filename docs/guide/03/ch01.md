# 第 1 章 总论 · AI 时代怎么"学"一门语言

过去学一门编程语言，意味着背语法、做习题、亲手写出每一行，产出代码的是你。现在产出代码的是 AI，你的角色是验收，第二册整册都在练这件事。角色变了，要学的东西跟着变，<strong>审查的前提是看得懂</strong>。你每天在差异视图里看红绿，如果那些行本身是天书，审查就只是仪式。

所以本册给每门语言定一把三层的标尺。第一层，<strong>读得懂</strong>，拿到一个文件，说得出它在干什么，每一块各是什么角色。第二层，<strong>改得动</strong>，能安全地做小改，换句文案，调个数字，加一行。第三层，<strong>认得出问题</strong>，哪里可疑，哪里和需求不符，红线有没有被踩到。本册把每门语言都推到第一层，把几门重点语言推到第二、三层。

三个通用心法，先立在这里。<strong>其一，认脸先于认字。</strong>每门语言有自己的面相，HTML 满眼尖括号，CSS 满眼冒号分号花括号，JS 满眼 `const` 和 `=>`，JSON 满眼引号。文件后缀是身份证，面相是长相。两样对上，你已经知道自己面对的是谁。<strong>其二，角色先于语法。</strong>第一册第 1 章说过，网页由 HTML（骨架）、CSS（皮肤）、JS（动作）拼成。拿到任何文件先答一道选择题，它是骨架、皮肤、动作、数据，还是文档？答对这题，文件已经读懂一半。<strong>其三，读真文件，不读教程。</strong>教程里的例子是无菌室，你的项目才是真实世界。读法三步，先看整体形状，分几大块。再认每块的角色。最后挑最不懂的一小块逐行问 AI，它是世上最有耐心的陪读。

::: info 关键领悟
语法可以忘，角色不能忘。每一章要你带走的只有一句，"这门语言负责回答什么问题"。
:::

::: tip 试一试
打开我们的主仓库，数一数一共出现了几种文件后缀，给每一种预先猜一个角色，把猜测记下来。读完本册回来对答案，这份错题单比任何笔记都值钱。
:::
