# 第 1 章 当你按下回车：一个网页的诞生

打开浏览器，输入一个网址，按下回车。在接下来的半秒钟里，发生了一连串你从未见过的事。

浏览器先去问一个叫 <strong>DNS</strong> 的系统："这个名字对应的是哪台电脑？"（DNS 是什么，第 6 章细讲，先记住它是个"翻译名字的电话簿"。）拿到答案后，浏览器找到了地球某处一台永远开着机的电脑——<strong>服务器（Server）</strong>。你的浏览器在这场对话里叫<strong>客户端（Client）</strong>，它向服务器发出一个<strong>请求（Request）</strong>："把这个页面给我。"服务器回一个<strong>响应（Response）</strong>，里面装着几种文件：HTML（页面的骨架）、CSS（皮肤和化妆）、JavaScript（动作和交互）。浏览器把它们"画"出来，就是你看到的网页。

用点外卖来理解：你是客户端，餐厅是服务器；下单是请求，出餐是响应；而双方约好的沟通格式——单子怎么填、怎么送——就是 <strong>HTTP</strong>。你常看到的 <strong>HTTPS</strong> 多出来的 S 是加密（Secure）：把信装进只有你们俩能打开的信封，中途谁也偷看不了、篡改不了。现在正经网站都必须是 HTTPS。

这一章只想让你记住一件事：<strong>整个互联网，本质上就是无数次"请求—响应"</strong>。你以后做的每一个功能、调的每一个接口，都是在扮演提问的一方，或者回答的一方。想清楚"谁在问、谁在答、问的是什么"，很多看起来复杂的东西会突然变简单。

::: tip 试一试
随便打开一个网页，按 F12 打开开发者工具，切到 Network（网络）面板，刷新页面——你会亲眼看到那半秒钟里的每一次请求和响应。
:::
