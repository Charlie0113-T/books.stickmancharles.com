# 附录 C · 红线卡：危险动作清单

> 可以打印出来贴在桌前。看到 AI 要做这些事时，停下，人来确认。

- <strong>`rm -rf`</strong> 或任何批量删除——终端删除没有回收站。
- <strong>`git push --force`</strong>——会覆盖云端历史，多人协作时是灾难。
- <strong>一切触碰"已部署合约"的改动</strong>——链上的东西改不了，只能配合它。
- <strong>直接操作生产数据库</strong>（删表、清数据、跑大范围 UPDATE）——先备份，先在预览环境试。
- <strong>给真实用户群发</strong>（邮件、通知）——先发给自己，检查无误再放行。
- <strong>花真钱的操作</strong>（铸造、转账、购买服务）——金额、地址、次数，逐项人眼核对。
- <strong>泄露的 Key</strong>——只作废换新，不要只删代码；Git 历史里它还在。
- <strong>改域名 DNS 记录</strong>——写错一条，全站失联；改前截图留底。

规则只有一句：<strong>可逆的事，放手让 AI 跑；不可逆的事，人是最后一道闸。</strong>
