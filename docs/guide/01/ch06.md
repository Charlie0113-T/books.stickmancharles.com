# 第 6 章 域名与 DNS · 互联网的门牌与电话簿

每台联网的电脑都有个真实门牌号，叫 <strong>IP 地址</strong>，一串类似 `76.76.21.21` 的数字。机器认它，人记不住它。于是人类发明了<strong>域名（Domain）</strong>，给门牌号起个名字。

把名字翻译回号码的系统，就是 <strong>DNS</strong>（Domain Name System）。它像全世界共用的一本联系人电话簿，你存的是"家"，打电话时手机自动翻译成号码。第 1 章那半秒钟里的第一步，就是查这本电话簿。

买域名，买的其实是每年付费租用这个名字的权利，卖家叫注册商。买完之后，你要往电话簿里写几条 <strong>DNS 记录</strong>，最常见四种。<strong>A 记录</strong>把名字指向一个 IP，等于说这个名字住在这台机器。<strong>CNAME</strong> 把名字指向另一个名字，找它就等于找它，把域名指到 Vercel 用的就是这种。<strong>TXT</strong> 像在名片上贴张便签，最常见的用途是证明这个域名归我，所以 Resend、Google 这类服务让你验证域名时，都是让你加 TXT 记录。<strong>MX</strong> 负责说清发给这个域名的邮件该往哪送。

顺带认识一下我们家的电话簿管理员，<strong>Cloudflare</strong>。我们的域名记录就写在它那里。除了当电话簿，它还兼任门口的调度员和保安（CDN 分发与安全防护），它还能干的那些事，第四册专门讲。

两个每个人都会撞上的现象。其一，<strong>改了 DNS 为什么不马上生效？</strong>全世界有无数份电话簿的缓存副本，要按各自的有效期（TTL）陆续更新，这个过程叫传播，从几分钟到一两天不等。其二，<strong>HTTPS 的锁是哪来的？</strong>网站需要一张证书来证明身份并加密通信。好消息是 Vercel 这类平台现在都自动帮你申请续期，你只要知道那把锁的含义就行。

::: info 关键领悟
DNS 出问题的症状千奇百怪，一部分人打得开一部分人打不开，刚改完不生效，邮件收不到。以后遇到这类玄学，第一反应应该是电话簿还没更新完，或者哪条记录写错了。
:::
