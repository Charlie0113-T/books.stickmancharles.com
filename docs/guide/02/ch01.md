# 第 1 章 你的驾驶舱 · 把 VS Code 认全

VS Code 是我们每天坐进去的驾驶舱，值得花十分钟把每块仪表认全。

最左边一竖条图标叫<strong>活动栏</strong>，常用的有五个。<strong>资源管理器</strong>，文件树，项目的目录结构。<strong>搜索</strong>，全项目范围的搜索和替换，比一个文件一个文件翻快一百倍。<strong>源代码管理</strong>，重点，它就是 Git 的图形界面，下文细说。<strong>运行调试</strong>。<strong>扩展</strong>，插件商店，Claude 插件就装在这里。中间是<strong>编辑区</strong>，每个打开的文件一个标签页，拖动标签可以左右分屏对照着看。底部一条<strong>状态栏</strong>，左下角那个小小的名字千万别忽略，<strong>那是你当前所在的 Git 分支</strong>，第 7 章讲分支时你会庆幸自己早就知道它在哪。

两个"任意门"快捷键，值得练成肌肉记忆。`Cmd/Ctrl + P`，输入文件名片段直接跳到任何文件。`Cmd/Ctrl + Shift + P` 打开<strong>命令面板</strong>，把你想对编辑器做的任何事打几个字母出来，相当于编辑器自己的终端。再按 `` Ctrl + ` `` 会在底部弹出<strong>集成终端</strong>，就是第一册第 7 章那个终端，只是嵌进了编辑器。AI 敲命令，多数时候就敲在这里，当着你的面。

重点看<strong>源代码管理面板</strong>。你改动过的文件会自动列在这里。点开任何一个，看到的是<strong>差异视图（Diff）</strong>，红色是删掉的，绿色是新增的。文件旁的 `+` 号、上方输入框旁的 `√`、菜单里的"推送"，这些按钮背后分别就是 `git add`、`git commit`、`git push`，第 5 章细讲。<strong>图形界面和命令行是同一件事的两张脸</strong>，两张脸都认识，你才能既自己点得动，又看得懂 AI 在终端里做的是同一回事。

::: info 关键领悟
VS Code 里几乎每个按钮背后，都是一条你在第一册见过名字的命令。
:::

::: tip 试一试
随便改动一个文件里的一个字，去源代码管理面板看它出现，点开看红绿差异，再用文件上的"放弃更改"图标把它撤销掉。
:::
