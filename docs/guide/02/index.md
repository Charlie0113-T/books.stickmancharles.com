## 小序

这一册只练我们真实的工作方式。我们的主战场有两个：<strong>VS Code 里的 Claude 插件</strong>（贴身搭档，坐在你旁边一起改）和 <strong>Claude Code 网页版</strong>（云端分身，派活出去、收货回来）。终端是配角——我们很少亲自开它，但它是 AI 的手脚，所以第 4 章要把它彻底看懂。

开读之前，先做一件事：<strong>建一块试验田</strong>。新建一个叫 `playground` 的文件夹，本册所有"试一试"都在里面做。它存在的意义就是被随便折腾、随便搞砸——在试验田里砸过的坑，正式项目里就不会再掉进去。

界面细节（按钮长相、菜单位置）会随版本更新，以你眼前的为准；但本册教的<strong>工作循环</strong>不会变。
