# 第 4 章 命令行生存包 · 组合技与肌肉记忆

第一册第 7 章给了你十个命令的"单词表"，这一章教"造句"。目标依旧，自己偶尔用得上，更重要的是看懂 AI 的每一步。

先练四个<strong>肌肉记忆</strong>，它们不解决问题，但让你在终端里不狼狈。<strong>Tab 补全</strong>，路径和文件名打头几个字母就按 Tab，终端替你补全。这是终端世界最重要的一个键，从此告别拼写错误。<strong>↑ 方向键</strong>，翻出刚才敲过的命令，改一改再跑。<strong>Ctrl + C</strong>，强行中断当前正在跑的程序，卡住了、跑错了，都是它。`clear`，清屏，还你一张干净桌子。

再学三个<strong>组合技</strong>。通配符 `*` 代表任意内容，`ls *.md` 列出所有 Markdown 文件。`grep -r "关键词" .` 在当前目录下<strong>递归搜索</strong>每一个文件，想知道某个函数在项目里哪些地方被用过，一行搞定，这正是 VS Code 搜索面板背后的原理。看日志有专用组合，`tail -20 文件` 看文件最后二十行，`tail -f 文件` 则<strong>持续追着看</strong>，新日志一来就滚出来，盯着服务的实时输出时就是它。

还有两个日常小工具。`which 命令名` 和 `命令名 --version`，查某个工具装没装、装的什么版本，AI 排查环境问题时最先跑的就是这类命令。`open .`（Mac）或 `explorer .`（Windows）把当前目录在图形界面里打开，两个世界随时互通。系统差异说一句就够，本书命令以 Mac / Linux 为准，Windows 的 PowerShell 大多相通，遇到不认的命令，把报错丢给 AI。

::: info 关键领悟
终端的高手气质来自 Tab、↑、Ctrl+C 这三个键用得毫不犹豫，和记住多少命令关系不大。
:::

::: tip 试一试
在 `playground` 里用 `grep -r` 搜一个词，再用 `tail` 看任意文件的最后几行。全程强制自己用 Tab 补全每一个路径。
:::
