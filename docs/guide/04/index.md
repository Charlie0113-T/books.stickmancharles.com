## 小序

前三册教你在这个世界里开车：认地图、握方向盘、读路牌。你已经能用四大件（Cloudflare + Vercel + Supabase + DO）做出真东西了。但"会用"和"懂它"之间隔着一层薄板，平时感觉不到——<strong>出事的那天，这层薄板就是天堑</strong>。这一册把板子掀开。

十章的路线：先逐个打开四大件里最陌生的两件（Cloudflare 这位门口的保安、DO 那台裸服务器），再补上把一切连起来的隐形零件（进程与服务、端口与代理），然后深入数据这一层（表设计、RLS 权限），最后是三门"懂系统的人才有"的功课：API 设计、性能与缓存、日志监控，以及——读账单。

本册有个贯穿装置：每章末尾多一条"<strong>出事时想起我</strong>"，列出这一层出毛病时的典型症状。十章读完，你会攒出一张"症状 → 层"的对照表。这张表是工程师身上最值钱的直觉：别人看到的是"网站坏了"，你看到的是"这个症状属于第几层，该翻哪本日志"。

最后一件事说在前头：<strong>本册的试一试，第一次真正触碰生产环境。</strong>所以规矩升级——每个试一试都标了安全档位，默认从"只读"开始；标 ⚠ 的，先在测试环境走熟，或者和爸爸一起做。开读之前，把第一册附录 C 的红线卡找出来，放在手边。引擎盖下面没有魔法，但有高压电。
