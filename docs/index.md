## 这套书是怎么来的

一对父子——12 岁的 Charles 和 47 岁的 Roy——用 AI 编程做出过真东西：跑在区块链上的合约，插在树莓派上的读卡器，被真实用户打开过的网站。但总有一种"上限被压低"的感觉，直到想明白：缺的不是能力，是一张**地图**。

这套书就是那张地图。它由 Charles 与 Claude 协作写成——这本身就是书里讲的工作方式。所有例子来自我们自己的项目和真实付过的学费。

> 谨以此书献给我的父亲，Roy。感谢他一直以来对我做项目的支持与肯定。也是他用实际行动告诉了我——**只要想学，最好的时间就是现在。**
