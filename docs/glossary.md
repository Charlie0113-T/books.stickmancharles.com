## 01 看懂地图

> 这份表是活的：每征服一个新词，就自己加一行。

**网络基础**
- **客户端（Client）**：发起请求的一方，通常是用户的浏览器或 App。
- **服务器（Server）**：响应请求的一方，一台永远开机、等人来问的电脑。
- **请求 / 响应（Request / Response）**：互联网对话的基本单位——一问一答。
- **HTTP / HTTPS**：客户端和服务器约定的说话格式；S 表示加密。
- **URL**：一个资源在互联网上的完整地址。
- **IP 地址（IP Address）**：每台联网设备的数字门牌号。
- **域名（Domain）**：给 IP 起的人类能记住的名字，按年付费租用。
- **DNS**：把域名翻译成 IP 的全球电话簿；A/CNAME/TXT/MX 是常见记录类型。
- **CDN**：把文件复制到全球各地节点、就近分发的网络。
- **缓存（Cache)**：把结果暂存起来下次直接用，快，但可能"旧"。

**前端与后端**
- **前端（Frontend）**：跑在用户设备上的那一半，用户看得见也改得了。
- **后端（Backend）**：跑在服务器上的那一半，掌管规则与数据。
- **HTML / CSS / JavaScript**：页面的骨架 / 皮肤 / 动作。
- **框架（Framework）**：一套现成的搭建方式和规矩，如 React。
- **React**：把界面拆成可复用"积木"（组件）来拼的前端框架。
- **组件（Component）**：界面积木，一块可复用的界面单元。
- **全栈（Full-stack）**：前后端都做，AI 时代你我默认就是全栈。

**数据与存储**
- **数据库（Database）**：专门负责"记住"的软件。
- **表 / 行 / 列（Table / Row / Column）**：数据的抽屉 / 一条记录 / 一个属性。
- **SQL**：和数据库说话的语言，核心是查增改删四个动词。
- **Postgres**：最流行的开源关系型数据库，Supabase 的地基。
- **Supabase**：托管好的 Postgres，附送登录、存储和现成 API。
- **迁移（Migration）**：把每次表结构变更写成脚本，让数据库历史可追溯、可重放。
- **Schema**：数据库的整体结构设计——有哪些表、各有哪些列。
- **RLS（Row Level Security）**：行级权限——规定谁能看、能改哪些行。不开约等于公开。
- **Auth**：登录与身份系统。永远用现成的，别自己造。

**API 与集成**
- **API**：软件为其他软件开的服务窗口。
- **REST**：最流行的 API 风格——URL 是名词，HTTP 方法是动词。
- **端点（Endpoint）**：API 的一个具体窗口，如 `GET /certificates/123`。
- **JSON**：软件之间传数据的通用格式，"名字: 值"的组合。
- **API Key**：调用 API 的通行证，属于秘密。
- **Token**：广义的"凭证/令牌"。注意 AI 语境里另有含义：文本的计量单位。
- **Webhook**：反向的 API——你留个网址，对方那边一有事就主动来敲门通知你。

**云与部署**
- **云（Cloud）**：别人机房里租给你的电脑和服务。
- **VPS / 服务器**：租的一整台永远开机的机器，全部自管。
- **Serverless**：不用管服务器的运行方式——函数被访问才唤醒，按次计费。
- **Function / Edge Function**：Serverless 里那段"被叫醒才干活"的代码。
- **Vercel**：前端全球分发 + 后端函数托管 + 连 GitHub 自动部署的平台。
- **部署（Deploy）**：把代码放到全世界能访问的地方跑起来。
- **构建（Build）**：把源代码翻译、打包成可上线成品的过程。
- **localhost**：你自己这台电脑；只有你访问得到。
- **开发 / 预览 / 生产环境（Dev / Preview / Production）**：私人试验田 / 每次改动的临时预览网址 / 真实用户用的正式版。
- **回滚（Rollback）**：一键退回上一个正常版本。
- **CI/CD**：push 后自动测试、自动部署的流水线的统称。

**版本控制**
- **Git**：代码的时间机器。
- **GitHub**：Git 仓库的云端家园与协作社区。
- **仓库（Repository / Repo）**：一个项目的全部代码和全部历史。
- **commit**：一个存档点，附一句改动说明。
- **branch / merge**：开平行宇宙试新想法 / 把宇宙合回主线。
- **push / pull / clone**：上传存档 / 拉取存档 / 整仓复制。
- **PR（Pull Request）**："我改好了，请过目后合并"的正式流程。
- **.gitignore**：告诉 Git"这些文件别拍进存档"的清单，`.env` 必须在列。

**依赖与工具**
- **库 / 包（Library / Package）**：别人写好打磨好的轮子。
- **npm / pip**：JavaScript / Python 世界的包管理器。
- **依赖（Dependency）**：你的项目用到的所有外部包。
- **package.json / lock 文件**：购物清单 / 把精确版本钉死的清单。
- **node_modules**：按清单搬回家的货，巨大而正常，可随时重装。
- **终端（Terminal / CLI）**：用命令和电脑对话的界面。
- **日志（Log）**：程序运行过程的流水账，排查问题的第一现场。
- **环境变量（Environment Variable）**：放在代码外面的配置与秘密口袋。
- **.env**：本地集中存放环境变量的文件，永不进 Git。

**AI 协作**
- **上下文（Context）**：AI 当前"视野"里的全部信息；有限，会被挤出去。
- **提示词（Prompt）**：你对 AI 说的话；质量决定产出。
- **Agent**：能自己计划、执行、观察、再计划的 AI 工作方式，Claude Code 即是。
- **幻觉（Hallucination）**：AI 一本正经的胡说。防它的方法是第 14 章。

**我们的世界**
- **区块链（Blockchain)**：一本全球共同记账、写上去就改不了的公共账本。
- **智能合约（Smart Contract）**：部署到链上就无法修改的程序——刻在石头上的后端，所以部署前的谨慎要乘一百。
- **铸造（Mint）**：在链上创造一个新的凭证/资产，不可逆操作的典型代表。

## 02 上手工具

- **活动栏 / 命令面板 / 集成终端**：VS Code 的侧边导航 / 万能命令入口（Cmd/Ctrl+Shift+P）/ 内嵌的终端。
- **差异（Diff）**：两版文件的对比视图，红删绿增。
- **沙箱（Sandbox）**：隔离的云端工作环境，Claude Code 网页版干活的地方。
- **工作区 / 暂存区 / 仓库**：稿纸 / 打包台（add 的去处）/ 存档柜（commit 的去处）。
- **远程仓库（Remote）/ origin**：云上的那份仓库 / 给它起的惯例联系人名。
- **main**：主分支的现行惯例名，"正式出版物"。
- **Merge / 合并**：把一条分支的成果并入另一条。
- **冲突（Conflict）与冲突标记**：两边改同一处时 Git 的"你们自己挑"，`<<< === >>>` 三行便签。
- **restore / revert / amend**：撤销工作区改动 / 用反向存档抵消已推送的提交 / 改写最近一次未推送的提交。
- **改写历史**：删改已共享的提交记录（reset --hard、force push），红线操作。
- **scripts / npm run**：package.json 里的快捷按钮区 / 按下快捷按钮。
- **.env.example**：环境变量清单模板，只列名字不含钥匙，可进 Git。
- **CLAUDE.md / 技能（Skill）**：项目宪法 / 可复用的专项规程。
- **审查（Review）**：合并前正眼看完全部差异并给出意见的过程——本册真正想教会你的事。

## 03 读懂语言

- **标签（Tag）/ 属性（Attribute）/ DOM**：HTML 的积木 / 积木上的设置项 / 那棵树在浏览器内存里的活体。
- **选择器（Selector）**：CSS 的"选中谁"，`.class` 最常用。
- **盒模型（Box Model）**：内容 → padding → border → margin，每个元素都是套娃矩形。
- **层叠（Cascade）**：多条规则撞车时，更具体、更靠后的赢。
- **Tailwind**：预制 class 字典，把样式直接挂在 HTML 的名牌位上。
- **箭头函数（=>）**：function 的现代简写。
- **事件（Event）/ addEventListener**："等某事发生，就执行这段"。
- **Node.js**：让 JS 离开浏览器、跑在服务器上的运行环境。
- **async / await**："去取数据，等它回来再继续"。
- **类型（Type）/ 类型标注**：变量的形状申报单；冒号后面那部分。
- **JSX / .tsx**：长在 JS/TS 里的 HTML；React 组件的家。
- **YAML**：用缩进代替花括号的配置语言，流水线的礼服；缩进即命。
- **front matter**：文档顶部两条 `---` 夹着的名片。
- **MDX**：Markdown + 可嵌组件，docs 网站的语言；大写开头 = 组件。
- **JOIN / 外键（Foreign Key）**：把两张表按"工号"拼起来 / 那个工号本身。
- **validator**：Aiken 合约里的门神函数，放行或拒绝每笔交易。
- **shebang（#!）**：脚本第一行，声明"本剧本由谁来演"。

## 04 深入系统

- **源站（Origin）**：门面（Cloudflare）背后真正干活的机器。
- **橙云（Proxied）**：Cloudflare 的核心开关——开了，一切流量先过它的手。
- **Purge**：主动清空 CDN 里的旧答案。
- **SSH / 密钥对**：加密的远程终端 / 门上的锁（公钥）与兜里的钥匙（私钥，永不外传，包括对 AI）。
- **指纹（Fingerprint）**：首次连接时记下的服务器"长相"，防冒充。
- **进程（Process）/ PID**：活过来的程序 / 它的编号。
- **systemd / unit / systemctl / journalctl**：服务管家 / 登记表 / 指挥口令 / 管家日记。
- **端口（Port）**：IP 是楼，端口是房间；80、443、22 三大名门。
- **反向代理（Reverse Proxy）/ Nginx**：替服务器在大门口接客的前台。
- **502 Bad Gateway**：前台在，后面的人死了。
- **主键 / 外键**：行的身份证 / 表间的工号——且由数据库强制守护。
- **索引（Index）**：书后的检索目录，用空间换时间。
- **RLS / policy / using / with check**：行级门规 / 开出的缝 / 管旧行 / 管新行。
- **auth.uid()**："现在敲门的这个人是谁"。
- **Bearer / Authorization 头**：钥匙的唯一正确携带位置——永不进 URL。
- **/v1**：对调用者的冻结承诺；改动进 /v2。
- **缓存（Cache）/ TTL / 失效**：记下的答案 / 保质期 / 扔掉旧答案。
- **Redis**：专职记答案的内存数据库，认脸即可。
- **uptime 探针**：每分钟替你打开一次网站的值班眼睛。
- **告警（Alert）**：只在需要行动时才响的铃。
- **free tier / 支出提醒**：免费额度 / 钱包的烟雾报警器。
