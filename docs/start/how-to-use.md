# 这个网站怎么用

这个站有两种用法，对应两种时刻。

**第一次来：按册读**。五册是一条设计好的阶梯（★ 到 ★★★★★），前后有伏笔和呼应，建议从[第一册](/guide/01/)顺着走。节奏是我们自己验证过的：**每晚一章，十分钟以内**。每章结尾有两样东西——"关键领悟"（这章真正要带走的一句话）和"试一试"（能立刻在自己项目里做的动作）。**试一试是这套书的灵魂：读懂的标志不是能解释，是敢动手。**

**回头查：按题查**。做项目时撞到一个词、一个报错、一个坑，直接进[速查](/reference/git)。每张速查卡都是薄页：三十秒的"认脸"、一分钟的"常见坑"，然后链回书里对应章节深读。也可以直接用搜索（右上角，`Ctrl/Cmd + K`）。

另外三个入口：[术语表](/glossary)是活的，由各册附录自动汇总，我们每征服一个新词就加一行；[项目](/projects/first-website)区只放真做过的东西；[许可](/license)写明这套书允许你拿它做什么。这个站的站规是**导航里只放写完的东西**，所以你点到的每一页都是真的。
