# 许可

这个站和这套书用两份许可证，因为它装着两种东西：**文字**和**代码**。

## 文字：CC BY-NC-ND 4.0

正文内容——书稿、速查页、项目页、站点文案——适用 [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/deed.zh-hans)（署名 — 非商业性使用 — 禁止演绎）。全文见仓库里的 `LICENSE-CONTENT.md`。

意思是：你可以自由地转载、打印、分发这套书，只要**署名**、**不拿去卖**、**不改动内容再发布**。

署名格式：

> Charles Tao，《AI 时代的编程指南》，books.stickmancharles.com

**翻译请来信，通常会同意。**ND 条款默认禁止改编（翻译在法律上算改编），但我不想把翻译这条路堵死——想把这套书翻成别的语言，写邮件聊，大概率是一句"去做吧"。

## 代码：MIT

书中出现的所有代码段，以及这个仓库里的代码（`scripts/` 装配脚本、`docs/.vitepress/` 站点配置与主题），适用 [MIT](https://opensource.org/license/mit)，全文见仓库里的 `LICENSE`。

为什么这么分？因为**代码存在的意义就是被复制和修改**。你从书里抄一段代码、改到面目全非、放进自己的项目、拿它赚钱——这正是我们希望发生的事。把"禁止演绎"套在代码上是错的，所以代码单独走 MIT，怎么用都行，署名都不必。

## 一句话总结

文字**照原样传播**，代码**随便拿去改**。拿不准的情况，来信问：<charlesisworkinghard@gmail.com>。
